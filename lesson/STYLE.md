# Style guide: Git week

For app copy, slides, and the lesson script.

## Voice
- A good TA at a whiteboard. Warm, direct, never cute.
- "You" and "we". Present tense. Active voice.
- Max 12 words per sentence. One idea each.
- Concrete: name the part, the card, the person.
- If a line can go, cut it.

## Words
- Plain word first, Git term second: "sticky note (branch)".
- One name per thing: card = commit, sticky note = branch, your pin = HEAD, draft = working copy, the Wall = remote, safety diary = reflog.
- "SHA", "ref", "HEAD" only inside Behind the door.
- No numbers you cannot cite.
- Banned: leverage, seamless, robust, simply, just, basically, powerful, magic, easy, obviously, clearly, really, actually, utilize, enable, intuitive, dive into.

## Four shapes
- **Problem.** The moment they just lived, as a fact or question.
- **Idea.** "Idea:" plus one sentence, no Git words. A student says it first.
- **How Git does it.** 2-3 lines: command, what it stores or moves, the rule. Simplify by saying less, never something false.
- **Pause.** "Ask:" one question. "Hope to hear:" its one-sentence answer. Wait 10 seconds.

Script labels only: Say, Do, Ask, Hope to hear, Watch for, Time.

## Before -> after
1. **Toast.** "Error: non-fast-forward. Simply pull and retry."
   -> "Refused: the Wall has cards you don't have. Press Get & combine first."
2. **Problem.** "Version control enables seamless collaboration."
   -> "What did your monster look like a minute ago? Who changed the legs?"
3. **Idea.** "Branches basically let you diverge from the main line."
   -> "Idea: each pair gets its own sticky note. Saving moves only yours."
4. **How Git does it.** "Git magically combines changes with a robust algorithm."
   -> "`git merge` finds the card both sides started from. Changed on one side: keep the change. Changed on both, differently: you decide."
5. **Pause.** "Any questions on revert vs reset?"
   -> "Ask: Why is a fix card safe, but moving the note back is not? Hope to hear: Others already have that card. A fix card only adds."
6. **Break.** "Let's take a quick break, then dive into remotes."
   -> "Time: 5 min. Say: 'Break. Back in 5 minutes.' Do: start the timer."
